# Camp Arena

A 2D real-time arcade multiplayer soccer game inspired by classic retro football titles. Powered by a cloud-native architecture on AWS.

## Architecture & Tech Stack

- **Game Server:** Java 21 (Spring Boot) with WebSockets
- **State Management:** AWS ElastiCache (Redis)
- **Infrastructure:** Terraform (IaC) on AWS (VPC, EKS, ECR, IAM)
- **Containerization:** Docker
- **CI/CD:** GitHub Actions
